# Blake-Bortles-Analysis

## Overview
Analysis of NFL data to investigate the performance of Jaguars' quarterback Blake Bortles across multiple seasons.

## Objective
Was Bortles always a decent quarterback held back by a weak team, or did the 2017 Jaguars succeed in spite of him?

## Data
Data was scraped by a user from reddit on r/datasets. They scraped game statistics from ESPN from 2002 to early 2019. This translates to about 4,500+ games being available in the dataset

## Tools Used
Python. Used the pandas, NumPy, matplotlib, and seaborn libraries.

## Methods
- Data cleaning
- Data analysis
- Visualization

## Key Findings
- 2017 was Bortles' best season at avoiding sacks, at about 1.5 per game versus roughly 2 to 4 in every other season. Sacks come from the offensive line as well as the quarterback, so this could reflect better protection, quicker throws, or both.
- 2017 was not a passing breakout. Average passing yards in 2017 (about 219 per game) were lower than in 2015 and 2016, and fell again in 2018. The AFC Championship run does not appear to have come from throwing the ball more productively.

## Folders
- code: code used to run my analysis
- data: data I conducted the analysis on
- documents: A write-up I made for my analysis. Includes my general findings and methodology

## How to Run
Download NFL.csv in data and Bortles_Jaguars_Analysis.ipynb in code. Organize both in the same folder. Then you should be able to run Bortles_Jaguars_Analysis.ipynb line-by-line without issue. If there is difficulty running the code, one may have to download certain packages into their work environment.
